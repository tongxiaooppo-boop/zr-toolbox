# ⑧ 跌多少要漲多少才回本：步驟 1 插圖「跌幅怎麼算」

（先貼 `00-風格與角色.md` 全文，再貼以下內容）

存檔名：`drawdown-step1.png`。放在精靈第 1 步「怎麼算跌幅」。

請畫一張直式插圖，上方標題：「跌幅有四種算法，選你手上有的」

小安站在上方，對話框：「我要跟什麼比？」

下面由上到下四個圓角框，左邊編號、右邊文字照寫，不能改：
1. 「跟買入價比 → 我還要漲多少才不虧」
2. 「跟最高點比 → 我還要漲多少才回到最高」
3. 「直接填跌幅 → 例：跌 30%」
4. 「貼一串淨值紀錄 → 找出最深的那一次」

第 1、2 條之間畫一條小折線：先往上到最高點、再往下，最高點標「最高點」、起點標「買入價」、終點標「現在」。

最下方一個藍色提示框，老師說：「同一個現價，跟買入價比和跟最高點比，答案不一樣。」
