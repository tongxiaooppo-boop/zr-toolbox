# ⑪ 正二要買多少：步驟 4 插圖「目標倍數＝大盤跌 10%，你跌幾 %」

（先貼 `00-風格與角色.md` 全文，再貼以下內容）

存檔名：`balance-step4.png`。放在精靈第 4 步「想要整體等於幾倍大盤」。

請畫一張直式插圖，上方標題：「目標倍數＝大盤跌 10%，你跌幾 %」

最上面一個大盤看板，箭頭向下，寫：「大盤 −10%」

下面由上到下三列，每列左邊是倍數標籤、右邊是小安的錢包往下的長條（越下面長條越長、顏色從綠到橘到紅）。文字、數字照寫，不能改：
- 「1 倍 → 你約跌 10%」（綠色，小安表情平靜）
- 「1.4 倍 → 你約跌 14%」（橘色，小安表情緊張）
- 「2 倍 → 你約跌 20%」（紅色，小安冒汗）

大盤漲的時候也一樣放大：在右上角放一個小框「大盤 +10% → 1.4 倍約漲 14%」

最下方老師說：「先想清楚跌的時候受不受得了，再決定倍數。」
最底一行小字：「粗估；正二的 2 倍是『每天』2 倍，放久了會偏離。」
