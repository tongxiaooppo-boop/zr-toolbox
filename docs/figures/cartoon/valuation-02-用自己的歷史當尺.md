# ⑯ 股價估價：步驟 3 插圖「用自己的歷史當尺」

（先貼 `00-風格與角色.md` 全文，再貼以下內容）

存檔名：`valuation-step3.png`。放在精靈第 3 步「你的三個倍數」。

請畫一張直式插圖，上方標題：「倍數怎麼定？看它自己過去幾年」

中間一條橫向的長條，從左到右標「本益比低」到「本益比高」，上面散佈很多小圓點（代表過去每一天的本益比）。
長條被兩條直線切成三段，每段下方的標籤照寫，不能改：
- 左段：「最低的四分之一 → 便宜 15 倍」
- 中段：「中間一半 → 合理 20 倍」
- 右段：「最高的四分之一 → 昂貴 25 倍」

小安站在左下，對話框：「原來是跟它自己比，不是跟別檔比！」

最下方一個藍色提示框，老師說：「過去的區間不代表未來；公司變了，區間也會變。」
