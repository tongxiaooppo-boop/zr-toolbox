# ㉑ 借錢投資的管道：四格漫畫「借錢之前先問三件事」

（先貼 `00-風格與角色.md` 全文，再貼以下內容）

存檔名：`loans-comic.png`。放在「借錢投資的管道」頁最上面「先看這張圖」。

請畫一張直式 2×2 四格漫畫，角色小安與老師。每格上方有一行標題，格內文字照下面寫，不能改、不能多加數字。不要寫真實銀行、券商名稱或股票代號。

**第 1 格｜標題「想借錢多買一點」**
小安看著一張寫「借錢」的單子，眼睛發亮對話框：「借來的錢拿去投資，賺更多？」

**第 2 格｜標題「第一問：利息多少」**
老師舉起一根手指，旁邊一個計算機圖示，對話框：「利息每個月都要付，不管賺還是賠。」

**第 3 格｜標題「第二問：會不會被追繳」**
一張下跌的股價線，旁邊紅色警示牌「追繳通知」。老師對話框：「拿股票去借，股價跌太多就要補錢，不補可能被賣掉。」

**第 4 格｜標題「第三問：最壞會怎樣」**
小安冒汗，看著白板，白板寫三行：
「虧損變成真的」
「還要繼續還錢」
「信用紀錄變差」
老師對話框：「三件事都想清楚，再決定要不要借。」

最底一行小字：「以上只是說明，不是借款建議。」
