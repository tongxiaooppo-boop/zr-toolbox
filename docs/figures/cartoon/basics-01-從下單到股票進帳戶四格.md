# ㉓ 股票基本術語：四格漫畫「從下單到股票進帳戶」

（先貼 `00-風格與角色.md` 全文，再貼以下內容）

存檔名：`basics-comic.png`。放在「股票基本術語」頁最上面「先看這張圖」。

請畫一張直式 2×2 四格漫畫，角色小安與老師。每格上方有一行標題，格內文字照下面寫，不能改、不能多加數字。不要寫真實券商、銀行名稱或股票代號。

**第 1 格｜標題「① 下委託單」**
手機畫面寫「券商 App（示意）」，畫面上三行：「買進」「1 張＝1,000 股」「限價 ROD」。小安對話框：「按下去就買到了嗎？」

**第 2 格｜標題「② 等配對成交」**
老師指著白板，白板左邊寫「委買」、右邊寫「委賣」，中間一個箭頭寫「價格對上才成交」。老師對話框：「送出委託，不代表已經成交。」

**第 3 格｜標題「③ T+2 交割」**
一個月曆，第一格寫「成交日」，往後數第二個營業日圈起來寫「交割日」。旁邊一個銀行存摺圖示寫「交割款要先放好」。小安冒汗對話框：「錢不夠會違約交割！」

**第 4 格｜標題「④ 股票進集保帳戶」**
一個寫著「集保帳戶」的保險箱，裡面放著寫「股票」的方塊。老師對話框：「股票記在集保，現金走銀行戶。」小安鬆一口氣。

最底一行小字：「流程簡化示意，實際以券商與交易所規定為準。」
