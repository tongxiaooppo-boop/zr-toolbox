3. 藍色卡片「目標倍數」：「先決定整體要幾倍大盤，再算正二買多少」
4. 橘色卡片「只買正二長抱」：「不配回，跌的時候沒有現金接」
5. 紅色卡片「借錢加碼」：「質押、融資、信貸，跌多會被追繳」
