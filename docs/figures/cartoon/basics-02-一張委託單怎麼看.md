# ㉓ 股票基本術語：插圖「一張委託單怎麼看」

（先貼 `00-風格與角色.md` 全文，再貼以下內容）

存檔名：`basics-map.png`。放在「股票基本術語」頁第二節「下單」。

請畫一張直式插圖，上方標題：「一張委託單，要選這四件事」

中間是一張大大的委託單（像手機下單畫面，最上方寫「券商 App（示意）」），由上到下四列，每列左邊一個標籤、右邊兩到三個選項按鈕，再下面一行說明，文字照寫，不能改：
1. 標籤「買或賣」：按鈕「買進」「賣出」；說明「先確認方向，按錯很麻煩」
2. 標籤「數量」：按鈕「整股（張）」「零股（股）」；說明「1 張＝1,000 股，零股另外撮合」
3. 標籤「價格」：按鈕「限價」「市價」；說明「限價：最多出到這個價；市價：不指定價格」
4. 標籤「有效時間」：按鈕「ROD」「IOC」「FOK」；說明「ROD 當日有效；IOC 先成交的留下、其餘取消；FOK 全部成交不然整筆取消」

老師站在右下角，對話框：「送出前，四件事再看一次。」

最下方一個藍色提示框：「送出委託≠成交，記得看成交回報。」
