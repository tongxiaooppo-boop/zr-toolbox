# ③ 定期配比再平衡：步驟 1 插圖「532 有兩種」

（先貼 `00-風格與角色.md` 全文，再貼以下內容）

存檔名：`rebalance-step1.png`。放在精靈第 1 步「選配置」。

請畫一張直式插圖，上方標題：「名字一樣叫 532，內容不一樣」

小安站在上方抓頭，對話框：「網路上說的 532，到底是哪一種？」

中間左右兩欄，各一個圓角框，框內三條橫向長條（長度照比例），文字照寫，不能改：
- 左欄標題「股版」：「原型 50%」「正二 30%」「現金 20%」，框底寫「約 1.1 倍大盤」
- 右欄標題「債版」：「正二 50%」「美債 30%」「現金 20%」，框底寫「約 1 倍大盤」

兩欄中間一個大大的「≠」。

最下方一個藍色提示框，老師說：「別人說 532 先問是哪一種。自訂也可以，但每一份加起來要剛好 100%。」
