# ㉑ 借錢投資的管道：插圖「押什麼借，差很多」

（先貼 `00-風格與角色.md` 全文，再貼以下內容）

存檔名：`loans-map.png`。放在「借錢投資的管道」頁「先分三類」那一節。

請畫一張直式插圖，上方標題：「押什麼借，差很多」

由上到下三個大方框，每框左邊一個圖示、右邊三行字，文字照寫，不能改：

1. 紅色框，圖示是一疊股票憑證，標題「押股票」
   - 「股票質借、融資、融券、借券」
   - 「股價跌太多會被追繳，不補可能被賣掉」
   - 「例：融資整戶維持率低於 130%，要在 2 個營業日內補」

2. 橘色框，圖示是房子、保單、汽車、定存單，標題「押房子、保單、車、定存」
   - 「房貸增貸、理財型房貸、保單質借、車貸、存單質借」
   - 「不會因為股價每天追繳」
   - 「還不出來，擔保品可能被處分」

3. 藍色框，圖示是一張信用卡和一份文件，標題「什麼都不押」
   - 「個人信貸、信用卡預借現金、循環信用」
   - 「不會追繳，但利息通常比較高」
   - 「遲繳會影響信用紀錄」

老師站在右下角，對話框：「不會追繳，不代表不會虧。」
