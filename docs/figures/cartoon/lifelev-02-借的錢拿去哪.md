# ⑬ 人生槓桿體檢：步驟 3 插圖「借的錢拿去哪」

（先貼 `00-風格與角色.md` 全文，再貼以下內容）

存檔名：`lifelev-step3.png`。放在精靈第 3 步「你的借款」。

請畫一張直式插圖，上方標題：「同樣是借錢，算法不一樣」

小安站在上方抓頭，對話框：「房貸也要算進股票的槓桿嗎？」

中間左右兩欄，各一個圓角框，文字照寫，不能改：
- 左欄標題「拿去買股票」：框內三個小標籤「信貸」「股票質押」「融資」，框底寫「從金融淨資產扣掉」
- 右欄標題「拿去買房子」：框內一個小標籤「房貸」，框底寫「不扣金融淨資產，每月還款照算」

兩欄下方畫一個箭頭，從右欄的「房貸」指向左欄，箭頭旁寫：「房貸增貸拿去買股票的那一部分 → 算左邊」

最下方一個藍色提示框，老師說：「每筆借款都填『拿去投資多少』。質押、融資留白就當全部。」
