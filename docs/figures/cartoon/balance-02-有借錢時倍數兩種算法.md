# ⑪ 正二要買多少：步驟 3 插圖「有借錢時，倍數有兩種算法」

（先貼 `00-風格與角色.md` 全文，再貼以下內容）

存檔名：`balance-step3.png`。放在精靈第 3 步「現金與借款」。

請畫一張直式插圖，上方標題：「有借錢時，倍數有兩種算法」

最上面一排小方塊（文字、數字照寫）：「股票 1,000 萬」「現金 200 萬」「借款 300 萬」（借款用紅色）

中間左右兩個區塊（文字、數字照寫，不能改）：

**左：灰色區「總資產口徑（不扣借款）」**
- 「總資產＝1,000＋200＝1,200 萬」
- 「1,000 萬 ÷ 1,200 萬 ≈ 0.83 倍」
- 小字：「看起來比大盤還保守」

**右：藍色區「淨資產口徑（扣掉借款）」**
- 「淨資產＝1,200 − 300＝900 萬」
- 「1,000 萬 ÷ 900 萬 ≈ 1.11 倍」
- 小字：「這才是你自己的錢漲跌幾倍」

下方小安疑惑表情：「同一個人，怎麼有兩個答案？」
老師說：「借來的錢要還，跌的是你自己的錢。有借錢，看淨資產口徑。」
最底一行小字：「沒有借錢時，兩種算法一樣。」
