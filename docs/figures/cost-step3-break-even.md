請畫一張教學用 SVG 圖，放在手機與桌面網頁「買賣成本與損益」逐步精靈的第 3 步「打算賣在多少」。讀者是不懂術語的台灣投資新手。只輸出 SVG 原始碼（從 <svg 開始到 </svg> 結束），不要任何說明文字、不要 markdown 圍欄。

## 要表達的事（數字一個都不能改）
「損益兩平價」：賣在多少才不虧。用一條水平數線（由左到右價格變高）。

頂部標題：「100 元買 1 張，要賣多少才不虧？」

數線上標四個點（點的左右位置照價格比例，100 到 101.5 之間）：
- 100 元：中性色，標「買入價」，下方小字「原價賣：虧 584 元」（危險色）
- 100.5 元：危險色，標「掛 100.5」，下方小字「還虧 86 元」
- 100.587 元：強調色虛線，標「理論不虧 100.587」
- 101 元：安全色實心圓加粗，標「實際掛 101」，下方小字「賺 412 元」
100.587 左邊的數線段塗淡危險色、右邊塗淡安全色。

數線下方一個小框：「100–500 元的股票每檔跳 0.5 元，100.587 掛不出去，要往上取到 101。」
最底一行次要色小字：「手續費 0.1425%、不打折、最低 20 元；股票證交稅 0.3%。」

## 技術規格（必須遵守）
- `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 360 H">`，寬 360，高 H 建議 240–320；不要設 width/height 屬性。
- 加 `<title>` 與 `<desc>`（中文，desc 用一兩句說明圖的內容給螢幕閱讀器）。
- 顏色寫在 SVG 內的 `<style>`，用 class 上色，並加 `@media (prefers-color-scheme: dark)` 覆蓋：
  淺色：文字 #1c2330、次要文字 #6b7482、主色 #2563eb、危險 #b91c1c、中性 #9aa3b2、強調 #b45309、線條 #c9ced6、安全 #15803d。
  深色：文字 #e8ebf0、次要文字 #9aa3b2、主色 #6ea0ff、危險 #f87171、中性 #6b7482、強調 #fbbf24、線條 #3a4250、安全 #4ade80。
  背景透明（不要畫整張底色矩形）。
- 字體 `font-family: -apple-system, "Segoe UI", "Noto Sans TC", sans-serif`；最小字級 12，標題 15–16。
- 不准用 <script>、<foreignObject>、外部圖片／字型／連結、filter、動畫。
- 文字不能超出 viewBox、不能互相重疊；中文用全形標點；金額寫「萬」不寫小數點以外的多餘位數。
