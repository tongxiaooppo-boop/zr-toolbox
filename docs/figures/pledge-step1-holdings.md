請畫一張教學用 SVG 圖，放在手機與桌面網頁「質押壓力測試」逐步精靈的說明區。讀者是不懂術語的台灣投資新手。只輸出 SVG 原始碼（從 <svg 開始到 </svg> 結束），不要任何說明文字、不要 markdown 圍欄。

## 要表達的事（數字一個都不能改）
步驟 1「你拿去質押的股票」：教新手從券商 App 的「庫存」畫面找到要填的三個數字。

畫一個**通用的手機 App 庫存畫面示意**（圓角手機外框，內有一列表格；不要畫任何券商的名稱、商標或配色特徵，標題只寫「庫存（示意）」）：
- 表頭：「代號／名稱」「股數」「成本均價」「現價」
- 一列資料：「0050 元大台灣50」「10,000」「80.00」「100.00」

右側（或下方）三個標籤，用主色箭頭分別指向畫面上的欄位：
- 指向代號：「① 股票代號 → 填 0050」
- 指向股數：「② 買入股數 → 填 10000（1 張＝1000 股）」
- 指向成本均價：「③ 買入價 → 填 80」
現價那欄用次要色標：「現價會自動抓，不用填」。

最底一行次要色小字：「各家 App 欄位名稱可能不同：股數也叫「庫存股數」，成本均價也叫「平均成本」。」

## 技術規格（必須遵守）
- `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 360 H">`，寬 360，高 H 建議 300–400；不要設 width/height 屬性。
- 加 `<title>` 與 `<desc>`（中文，desc 用一兩句說明圖的內容給螢幕閱讀器）。
- 顏色寫在 SVG 內的 `<style>`，用 class 上色，並加 `@media (prefers-color-scheme: dark)` 覆蓋：
  淺色：文字 #1c2330、次要文字 #6b7482、主色 #2563eb、危險 #b91c1c、中性 #9aa3b2、強調 #b45309、線條 #c9ced6、安全 #15803d。
  深色：文字 #e8ebf0、次要文字 #9aa3b2、主色 #6ea0ff、危險 #f87171、中性 #6b7482、強調 #fbbf24、線條 #3a4250、安全 #4ade80。
  背景透明（不要畫整張底色矩形）。
- 字體 `font-family: -apple-system, "Segoe UI", "Noto Sans TC", sans-serif`；最小字級 12，標題 15–16。
- 不准用 <script>、<foreignObject>、外部圖片／字型／連結、filter、動畫。
- 文字不能超出 viewBox、不能互相重疊；中文用全形標點；金額寫「萬」不寫小數點以外的多餘位數。
