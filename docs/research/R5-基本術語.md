# R5：股票基本術語

查閱日期：2026-11-09。優先依交易所、櫃買、集保及期交所原始制度，例子以情境表達，制度數字附查閱年與本機來源。以下是科普，不是投資建議；不重收任務列出的既有辭典詞。因來源主要是市場作業說明，本文將「盤後」限定盤後定價，「開盤價」說明開盤集合撮合，不新增既有「收盤價」詞條。表內例子不代表實際報價、交易建議或未來走勢。
