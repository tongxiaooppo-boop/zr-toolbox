公式與原碼證據（各片段不超過 5 行）：

朋友一般模式令 S＝原型市值，D＝Σ原型市值×Beta，L＝目前正二市值，b＝正二加權 Beta，A＝S+L+C，N＝A−負債。未需新增借款時，**X=max(0,(B×所選分母−D)/b)**，買賣額 X−L；可用現金＝C−最低保留。資產口徑需借款且 b>B 時，**X=[B×(A−L−可用現金)−D]/(b−B)**。來源 O-01 HTML 第 237–250 行：

```js
let X = (B * base - D) / bw;
```

```js
if (basis === 'asset' && bw > B) {
  const X1 = (B * (A - L - avail) - D) / (bw - B);
  if (X1 > X) { X = X1; delta = X - L; }
}
```

C 獨立重算（單位萬）：X=(1.4×1000−1000)/(2−1.4)=666.666667；借款 X−200＝466.666667；新總資產＝1666.666667、新淨資產＝900；曝險＝1000+2X＝2333.333333；資產 Beta＝1.4、淨 Beta＝2.592593。原頁「目標 Beta 曝險額」仍列 B×借前 A＝1680 萬，和借後達標曝險 2333.3333 萬不同，教學應說明該行以借前基準計，不宜直接當借後曝險。

const targetLetf = totalAssets * targetLetfPercent / 100;
const targetMarketExposure = targetBase + targetLetf * 2;
const targetActualExposure =
  netValue > 0 ? targetMarketExposure / netValue : 0;
