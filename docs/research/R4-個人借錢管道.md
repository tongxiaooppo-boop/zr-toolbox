# R4：個人借錢管道

查閱日期：2026-11-09。優先使用主管機關、證交所現行規章，其次為產業公會及業者官網產品／利率公告；業者教學僅作次級資料並明示。以下整理台灣個人可接觸的借款、借股及用途限定融通，另列政策方案適用邊界，不是投資建議、不是任何借款業者推薦，也不保證所有可能的私人契約均已窮盡。公告利率、最低起價、APR範例、法定上限與個人核定價分開標示；「待查」不以印象補數字。費用均為新臺幣，利率區間只代表所列業者與版本，不能據此排名。原文保存本機，最後欄位的每個網址均有對應筆記。④為質押工具、⑤為融資融券、⑬為負債月付與總曝險；非股票擔保品的計價及證金契約不能直接套用④現有公式。

## 新手常見誤解

- 誤解：質借利率低，就比信貸安全。｜實際：利率不是風險上限，股票擔保會洗價追繳，無擔保信貸則有月付與信用負擔。｜來源：[本機](來源/R4-26_證交所：不限用途借貸操作辦法.md)；[本機](來源/R4-05_永豐銀行：數位信用貸款.md)
- 誤解：所有股票借款都在同一維持率追繳。｜實際：券商不限用途、信用交易、證金基金借款與銀行契約是不同制度，基金借貸分母還含應收利息。｜來源：[本機](來源/R4-26_證交所：不限用途借貸操作辦法.md)；[本機](來源/R4-28_證交所：融資融券操作辦法.md)；[本機](來源/R4-14_基富通：好享貸基金借貸.md)
- 誤解：回到追繳線就解除追繳。｜實際：暫不處分與取消紀錄不同，之後再跌破可能要當日下午補繳。｜來源：[本機](來源/R4-28_證交所：融資融券操作辦法.md)
- 誤解：融券利率就是借股成本。｜實際：要辨認券商付給客戶的價金／保證金利息，另有融券費、手續費及可能的券源費用。｜來源：[本機](來源/R4-20_永豐金證券：融資融券契約.md)；[本機](來源/R4-02_元大證券：借貸利率公告.md)
- 誤解：出借股票就是借錢投資。｜實際：出借方提供股票賺取收入；借入方才要付費並返還證券。｜來源：[本機](來源/R4-15_元大證券：股票借貸與債券擔保品.md)
- 誤解：理財型房貸沒動用，就完全沒有成本。｜實際：未動用不生借款利息，但開辦等費用仍可能發生；動用後只繳息也沒有減少本金。｜來源：[本機](來源/R4-08_凱基銀行：理財型房貸.md)
- 誤解：保單借款不影響保險。｜實際：未還本息達保單條款限制可能停效，理賠也可能先扣未償款。｜來源：[本機](來源/R4-09_國泰人壽：保單借款.md)
- 誤解：信用卡循環法定上限就是所有費用加總的上限。｜實際：循環利率上限與預借現金每筆手續費不同，銀行手續費不能冒稱法定數字。｜來源：[本機](來源/R4-19_金管會：銀行法.md)；[本機](來源/R4-10_玉山銀行：預借現金.md)
- 誤解：刷卡投資等於免息拿銀行錢。｜實際：若把應繳卡費現金拿去投資，經濟上是在借循環或分期卡債；一般台股不能直接刷卡交割，部分投資交易亦不符合分期資格。｜來源：[本機](來源/R4-11_玉山銀行：刷卡分期.md)；[本機](來源/R4-10_玉山銀行：預借現金.md)
- 誤解：房貸增貸最高成數就是額外可領的金額。｜實際：要重新鑑價並評估原有餘額與收入負債，不是原房貸之外再加整份成數。｜來源：[本機](來源/R4-07_國泰世華：房屋增貸.md)
- 誤解：斷頭後把擔保品交出去就不欠錢。｜實際：處分所得不足還可繼續追償，跌停也不保證賣得掉。｜來源：[本機](來源/R4-28_證交所：融資融券操作辦法.md)；[本機](來源/R4-20_永豐金證券：融資融券契約.md)
- 誤解：政府有低利貸款，個人就能隨時拿來買股。｜實際：紓困有開辦期間與生活困難資格，就學限教育支出，青創對象則是合格事業。｜來源：[本機](來源/R4-16_勞保局：115年紓困貸款.md)；[本機](來源/R4-24_臺灣銀行：就學貸款問答.md)；[本機](來源/R4-25_臺灣企銀：青年創業貸款.md)

## 待查與矛盾

- 銀行股票質借：永豐頁只列上市櫃股票及利率下限，未給ETF清單、完整成數、期限及追繳條款；證交所券商規章另有明確追繳制度。判斷：銀行管道存在，但ETF接受範圍與本人契約門檻待查，不借用券商數字。來源：[本機](來源/R4-01_永豐銀行：股票貸款.md)；[本機](來源/R4-26_證交所：不限用途借貸操作辦法.md)。
- 證金股票借款：元大證金頁確有個人開戶與借款；基富通基金合作頁列另一組維持率、補繳及解除條件。判斷：不能僅因同一家證金就將基金規則保證套用純股票借款，純股票利率與契約待查。來源：[本機](來源/R4-22_元大證金：股票借款.md)；[本機](來源/R4-14_基富通：好享貸基金借貸.md)。
- 合庫追繳文字：Q5前段說補足至高於130%，後方狀態表將130%以上列暫不處分、回升166%才取消追繳；證交所第20條亦區分兩種狀態。判斷：不是兩個安全上限互相替代，採完整流程。來源：[本機](來源/R4-21_合作金庫證券：不限輕鬆貸.md)；[本機](來源/R4-26_證交所：不限用途借貸操作辦法.md)。
- 合庫手續費單位：官網借款篇Q4寫「5%%（牌告8%%）」且每筆最低100元；元大利率公告沒有提供合庫費率。判斷：不可自行改成百分比或千分比，費率單位待查。來源：[本機](來源/R4-21_合作金庫證券：不限輕鬆貸.md)；[本機](來源/R4-02_元大證券：借貸利率公告.md)。
- 融券利率方向：元大公告列融券年利率0.2%，未在該行明示資金流向；永豐金契約第10條明列價金及保證金利息付給客戶，借券／融券費則另計。判斷：不得把0.2%宣稱為客戶借股全部成本，元大本人完整費用及其利率方向仍須以元大契約確認。來源：[本機](來源/R4-02_元大證券：借貸利率公告.md)；[本機](來源/R4-20_永豐金證券：融資融券契約.md)。
- 保單利率與停效：公會列國泰概覽區間，公司服務頁要求按保單查詢利率，停效僅描述本息超過保價特定比例。判斷：區間僅供概覽；沒有登入，個人核定年利率、停效比例、通知期限待查。來源：[本機](來源/R4-27_壽險公會：保單借款利率一覽.md)；[本機](來源/R4-09_國泰人壽：保單借款.md)。
- 基金利率：好享貸行銷比較表列「<4.5%」，但Q1-5說利率依元大證金公告調整，標的搜尋未取得個別報價。判斷：管道存在，不能以單一行銷上限補出完整年利率區間。來源：[本機](來源/R4-14_基富通：好享貸基金借貸.md)；[本機](來源/R4-22_元大證金：股票借款.md)。
- 債券質借：元大實務頁列公債、公司債、金融債擔保品，證交所第16條列各類成數。判斷：個人透過該券商業務有此管道；銀行特定信託受益權、海外債券、券種流動性與實際受理範圍待查，不能把債券ETF和直接持債混為一談。來源：[本機](來源/R4-15_元大證券：股票借貸與債券擔保品.md)；[本機](來源/R4-26_證交所：不限用途借貸操作辦法.md)。
- 黃金質借範圍：元大與證交所列的是合格黃金現貨；當舖法則是交付可收當動產的另一種業務。判斷：黃金現貨融通與實體金飾質當分開，不聲稱所有黃金存摺都可辦理。來源：[本機](來源/R4-15_元大證券：股票借貸與債券擔保品.md)；[本機](來源/R4-26_證交所：不限用途借貸操作辦法.md)；[本機](來源/R4-17_全國法規資料庫：當舖業法.md)。
- 存單利率：板信只提供定存利率加碼公式，未給每位存戶的原始存單利率；公會或其他銀行價格不能替代。判斷：不補總年利率，存單到期扣抵及超額質借條款仍待取得。來源：[本機](來源/R4-13_板信銀行：存單質借問答.md)。
- 原車融資：業者教學列概估利率並提醒實際以審核及產品頁為準；其月付示例不是正式產品報價。判斷：管道存在，但實際貸款總成本、期限、車輛處分流程、未清舊貸後的實撥額待查。來源：[本機](來源/R4-12_中租集團：原車融資說明.md)。
- 勞工紓困：勞保局公告利率及受理期是特定梯次資料，該梯已截止，不能保證2026-11-09仍受理或下一年度必定相同。判斷：管道存在，當前新申請與本人適用利率待查；生活紓困不列投資授權，未取得逐條買股禁令，不作額外法律結論。來源：[本機](來源/R4-16_勞保局：115年紓困貸款.md)。
- 其他政府專案：臺灣企銀青創貸款明列對象為事業，限營運週轉、場所與設備；臺銀就學貸款則由學生依教育費用申借。判斷：政府專案存在，但青創不是一般個人投資貸款，因此不混入個人可自由借款表；獨資負責人責任、微型創業、農漁、公教急難等其他專案須按當期對象另查，不能整包稱個人可借。來源：[本機](來源/R4-25_臺灣企銀：青年創業貸款.md)；[本機](來源/R4-24_臺灣銀行：就學貸款問答.md)。
- 當舖與民間：當舖法最高年率30%、倉棧費最高收當額5%；民法一般約定利率超過16%部分無效。判斷：法律適用不同，不是可任意選較高上限；均列最壞例子，不推薦。實際報價未取得。來源：[本機](來源/R4-17_全國法規資料庫：當舖業法.md)；[本機](來源/R4-18_全國法規資料庫：民法.md)。
- 證券交割與認股融通：元大公告有T+5、半年及認股價格，證交所依用途、期限與擔保安排分類。判斷：各子產品是否開辦、認股範圍、實際期限與短期補擔保契約仍待核，未用不限用途整戶規則取代。來源：[本機](來源/R4-02_元大證券：借貸利率公告.md)；[本機](來源/R4-29_證交所：證券業務借貸款項操作辦法.md)。
- 規章版本：證交所融資融券規章2026-10-16版標示第6條自2026-11-15實施；現有R2教學只作格式及背景參考。判斷：截至查閱日不預先採未生效的第6條，追繳按第54、55條；銀行與證金契約仍分開。來源：[本機](來源/R4-28_證交所：融資融券操作辦法.md)。
- 現金卡、P2P、雇主員工借款及其他私人安排：銀行法明列現金卡利率限制，民法涵蓋私人消費借貸，但未取得現行新戶可申辦的現金卡或特定平台／雇主方案。判斷：不把法律存在當作現有業者受理證明；私人借款歸民間及親友類，不推介平台。來源：[本機](來源/R4-19_金管會：銀行法.md)；[本機](來源/R4-18_全國法規資料庫：民法.md)。
