## 重點整理

頁面輸入現金／短債、原型 ETF、正二、負債的總金額，原型用 1、正二用 2、現金用 0 估計市場曝險，再除扣債後淨值。第三步不是填目標 Beta，而是填三類配置比例，按目前總資產重配，負債維持不變。可算買賣，但包括普通股的買賣，不等同朋友版預設固定普通股的方案。

## 關鍵數字

- HTML 第 4514 行 calculateTargetAllocation；4555–4560 行把目前總資產乘三類比例並重算曝險。
- A 換算百分比現金 5.833333%、原型 83.333333%、正二 10.833333%，原函式得正二 130 萬、淨 Beta 1.40、資產 Beta 1.05。
- B 換算百分比現金 3.414634%、原型 73.170732%、正二 23.414634%，原函式得正二 192 萬、買 172 萬、淨 Beta 1.20。
- C 改成現金 30%、原型 0%、正二 70%，結果正二 840 萬、資產 Beta 1.40、淨 Beta 1.87；必須賣全部原型，非朋友同交易方案。
- D 改成現金 20%、原型 80%、正二 0%，賣原型 200 萬達 Beta 0.80。

## 我的判讀

最接近的同類，沒有足夠證據稱為朋友工具來源。A/B 配比是研究者先反解，不是網站從 B 自動產生；step＝1 的小數百分比 UI 行為未操作。另跑原始預設 50/0/50，但其目標不同，不放進同目標比較。所有函式輸出存 O-07 JSON。
