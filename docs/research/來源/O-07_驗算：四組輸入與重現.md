## 重點整理

Node vm 只執行下載檔的相關計算函式；朋友的區段從 const $ 到 FinMind 區塊之前，T06 的區段從 const T 到 inputs.forEach 綁定事件之前，最後呼叫 calculate。DOM替身提供getElementById、querySelectorAll、querySelector與value、checked、innerHTML、textContent、style等，沒有模擬市場或改公式。T01 抽出 getPortfolio 與 runDropSimulator，提供逐檔輸入與數值讀取。T03 抽出 bands/compute 到 const owner 前，直接傳入資料物件。

一般持股輸入0050、Beta1、價格100，正二00685L、Beta2、價格20，權重空白；A/C股數100000/0，B60000/10000，D100000/0。A/B/C/D現金200萬/200萬/200萬/0，負債300萬/0/300萬/0，目標1.4/1.2/1.4/0.8；僅C用asset及借款true，其餘net及false，最低現金0。來源都是手動金額，不呼叫FinMind。

JSON鍵friendA–D為calc產生的完整HTML字串；T06A–D為預設50/0/50的原始輸入輸出元素；T06轉換A–D為另填報告所列百分比；T01A–D是getPortfolio物件；T01dropB/D是補充混合部位壓力輸出；T01疑點是全正二的舊研究疑點重現；T03A/C為compute回傳。A/C的T01診斷不包含負債，僅保留探索記錄，沒有作為完整同組測試證據。
