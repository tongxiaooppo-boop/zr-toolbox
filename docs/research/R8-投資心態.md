# R8：投資心態

查閱日期：2026-11-25。優先使用SEC、政府理財教育與主管機關資料；近因與沉沒成本另外採金融業者的原始教育文章並保留商業背景。下表的股災情境、可執行動作及工具對應由本研究改寫，屬於自我盤點流程，不是來源逐字建議，也不是買賣、加減碼或行情預測。偏誤名稱不是心理診斷。槓桿ETF與另外借款應分開理解；實際追繳依個人契約，已參照R4融資／質押段落，本次不重查門檻。
