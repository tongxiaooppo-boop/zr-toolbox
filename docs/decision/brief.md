## FinMind token 已查證（官方 finmind.github.io/Pricing、BanIPPolicy、update_token，2026-11-08）

- 不帶 token：300 次／小時；免費註冊會員：600 次／小時；付費 Backer 1,600、Sponsor 6,000。
- 額度超過回 HTTP 402；短時間大量 4xx（例：錯的或過期 token 一直重試）會封 IP 30 分鐘（403 ip banned）。
- 官方沒寫額度按 IP 或按什麼計；token 更新後舊 token 立刻失效。
- 原計算機：token 選填、只存在各自手機、每檔股票一次請求；程式碼裡沒有寫死 token。股價是**最近交易日收盤價，不是即時價**。
- Opus 初判：一般朋友各用各的手機與網路，不需要 token；同一公司 Wi‑Fi／電信共用出口 IP 時才可能撞 300 次。要做：收到 402 時顯示「去申請免費會員 token（600 次）」教學；收到 400／403 時停止重試。
