# 決策：三桶改版——保守（先留）拉出來，5/3/2 只分穩健／成長／積極（2026-11-26 定案）

取代 `決策-2026-11-25-投資屬性配置.md` 第 1 點（三桶內容）；比例表 `ALLOC` 不變。依據：R13 v2（`docs/research/R13-三桶商品查證.md`）。

## 決定

1. **保守（先留）不算在三桶裡**（使用者 2026-11-26）：生活預備金與近幾年要用的錢先留好，剩下的才分 5/3/2。
   - 要留多少：**6 個月生活費＋3 年內要用的錢**（Opus 建議，使用者同意）。結果頁用第 3 題（備用金）、第 6 題（多久不動用）提醒：`reservePlan`。
   - 例子：定存／活存、台幣貨幣市場基金、SGOV（只適合預留美元要用的錢）。
   - 界線（R13 v2）：上市的短債，以用款幣別算 2020、2022 兩年最大回撤都不超過 5% 才算保守（先留）。00719B、00865B、SHY 換成台幣都超過 5%，放穩健。
2. **三桶＝穩健／成長／積極**，程式 key 由 `safe` 改 `steady`。只有這三個名字，不再細分（使用者：不要分四類）。
3. **例子**（必須是台灣用證券戶、基金平台、複委託、銀行買得到的；使用者 2026-11-26）：
   - 穩健：短天期美債 ETF（00719B、00865B、SHY）、00720B（加註長天期，2020／2022 都跌近三成）、AOM／AOR、00713、00878、定存股只舉 2412。
   - 成長：0050、006208、0056、00646、00662、VT／VOO／SPY、QQQ。
   - 積極：正2 三檔、主動式 ETF（00981A）、主題型 ETF（00891、00757）、個股。
4. **保守型**：`ALLOC` 不動，讀成穩健 75–90／成長 10–25／積極 0（Opus 建議，使用者同意）。
5. 例子與一句註解寫死在 `js/core/riskquiz.js` 的 `RESERVE`、`BUCKETS`；㉗ 頁的 `BUCKET_GUIDE` 只放各桶標題、誰的主力、為什麼，不重複列商品。

## 否決的選項

- **R13 v2「跌得比 0050 少就算穩健」**：太寬。2886（2022 −35.5% vs 0050 −36.4%）、0056（−31.9%）跟大盤幾乎一樣深 → 0056 放成長，2886、5880 不列例子（個股統一在積極桶）。
- **保守穩健同一桶、桶內分兩層**：使用者不要分四類。
- **VT 放保守穩健**：100% 股票，2020 跌約三成五，放成長。
- **保守型不給 5/3/2**：保留查表，結果頁同時提醒先留保守。
