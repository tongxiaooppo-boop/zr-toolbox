# zr-calc 重新定義：決策文件（2026-11-08，待使用者拍板）

討論方式：同一份資料檔 [brief.md](brief.md) 交給 sol（gpt-6.1-sol high）、DeepSeek V4.1 Flash（代 Cline，Cline 寫程式暫停至 11/30）、Sonnet 各自獨立回答一次。原文：[sol.md](sol.md)、[deepseek.md](deepseek.md)、[sonnet.md](sonnet.md)。第一輪三方 D1／D3／D4／D5 一致，D2 只差 1–2 項，不開第二輪。新資訊：有（三條補充，見「採納的補充」）。

## 新定位

**「正二與股市計算機工具箱」**：手機優先的靜態 PWA。首頁是卡片，每張卡＝一個計算機；術語教學、範例、風險說明都藏在工具裡面（點 ⓘ 展開），不做成要從頭讀到尾的長文。朋友在用的原計算機網址不變，只加導覽。

## 採納的補充（三方各自提出、Opus 判斷成立）

1. **可執行不等於安全**（sol）：原計算機和質押壓測的結果旁固定顯示「可執行只代表資金夠，不代表跌了撐得住」，並連到壓測工具。
2. **預設值要標成「範例」**（Sonnet）：例如目標 1.4、借款 50% 這類數字，標成範例而不是建議值。免責文字固定放在每個工具的結果下方，語氣一致。
3. **PWA 更新提示**（DeepSeek）：朋友手機上裝的是快取版，新版上線時要提示「有新版本，點此更新」。舊的輸入資料格式要相容。

## 否決

- B 問題導向首頁：讀者常不知道自己要問什麼。只保留 3 個捷徑當作輕量版。
- C 保留長捲動研究頁：仍然像在讀報告。`research.html` 的計算模型與 20 項測試繼續沿用，內容拆進各工具卡。
- 原計算機改名改版：朋友會認不出來，所以只加副標。

## 對現有工作的影響

- `docs/P0-任務書.md`（重構原計算機）**擱置**。新方向不碰原公式，只加導覽、說明、token 處理，風險較低。
- `research-model.js` 的公式與測試直接沿用到工具 ②③④⑪。

## 開工前要使用者回答

1. 朋友在用的 GitHub Pages 網址或 repo 名稱是什麼？本機目錄不是 git repo，要先確認哪一份才是線上版本。
2. 新工具箱放在同一個網址底下（例如 `/` 是工具箱首頁，原計算機搬到 `/calc.html`？），還是原網址不動、工具箱放子路徑？**建議原網址不動**，工具箱放 `/tools/`，原計算機頂端加一個入口。
